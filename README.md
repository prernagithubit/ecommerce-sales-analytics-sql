# E-Commerce Sales Analytics using SQL

## Project Overview

This project simulates an e-commerce business database and uses SQL to answer real business questions.

The project demonstrates:

- Database Design
- SQL Joins
- Aggregate Functions
- Window Functions
- Common Table Expressions (CTEs)
- Views
- Stored Procedures
- Indexing
- Business KPI Analysis

## Tools Used

- MySQL 9
- MySQL Workbench
- Git
- GitHub
